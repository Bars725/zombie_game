# Арт и звук

Генерация в ComfyUI (Tripo — 3D, дорого по токенам; Mirelo — звуки, дёшево). Списки с промптами: `docs/ART_ASSETS.md`, `docs/SFX_ASSETS.md`.

- Модели: Husk ✅, пистолет ✅; дальше Runner → SMG → дробовик → пропсы (когда будут токены)
- Звуки P1 (12 шт.) ✅; дальше P2: шаги, приземление, появление врага, смена оружия, хитмаркер, фон, сирена
- Анимации: Mixamo (бесплатно, нужен Adobe-аккаунт) — отложено
