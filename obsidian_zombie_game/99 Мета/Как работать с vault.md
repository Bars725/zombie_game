# Как работать с vault

## Человеку
- Идеи — в [[Инбокс]] одной строкой. Можно и просто сказать ИИ в чате — он запишет сам.
- Можно править любую заметку. Если что-то решено — поставь `#решено`.

## ИИ (обязательно)
1. В начале сессии прочитать [[Инбокс]] и [[Roadmap]]; разобрать новые идеи: перенести в заметку системы со статусом `#идея`,
   в Инбоксе переместить строку в «Разобрано» со ссылкой. Неясное — спросить человека.
2. Решения из чата отражать в заметках сразу (статус `#решено`), реализованное — `#сделано`.
3. В конце сессии обновить [[Roadmap]] (и `docs/HANDOFF.md` — технический статус).
4. Vault — источник правды по **дизайну**; код и HANDOFF — по **реализации**. При расхождении спросить человека.
5. Язык заметок — русский. Не удалять чужие идеи; отклонённое помечать `#отложено` с причиной.
6. Файлы `.obsidian/workspace*.json` — личные настройки окна, в Git не идут.
